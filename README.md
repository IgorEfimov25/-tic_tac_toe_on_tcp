# -tic_tac_toe_on_tcp
Клиент-серверная реализация игры «Крестики-нолики» с обменом данными по TCP. Графический интерфейс реализован с помощью библиотеки txLib.

# Сетевая игра «Крестики-нолики» (TCP + txLib)

Курсовой проект, реализующий классическую игру **«Крестики-нолики»** для двух игроков по сети.  
Сетевое взаимодействие построено на **TCP-сокетах** — один игрок запускает сервер и ожидает подключения, второй подключается по IP-адресу и порту.

**Графический интерфейс** выполнен с использованием библиотеки **txLib** (The Dumb Artist Library) — лёгкой 2D-библиотеки для Win32 на C++[reference:0][reference:1]. Она обеспечивает отрисовку игрового поля, фигур (крестиков и ноликов) и обработку событий мыши.

**Основные возможности:**
- Полноценная игровая логика с проверкой победных комбинаций и ничьей.
- Обмен ходами через TCP-соединение (клиент-серверная архитектура).
- Графический интерфейс на txLib: интерактивное поле 3×3, визуальная обратная связь.
- Поддержка игры как на локальной машине (localhost), так и по локальной сети.

**Технологии:**  
C++, стандартная библиотека сокетов (Winsock2), txLib для GUI, многопоточность (или асинхронность) для обработки сетевых сообщений.
